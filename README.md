# Practical 5: Show/Hide Password

## Objective
To develop a password visibility toggle application using the `useState` hook and conditional rendering to improve user experience in authentication forms.

## Topics Covered
- `useState` Hook for Boolean State Toggling
- Conditional Rendering (Ternary Operator)
- Controlled Form Inputs
- Dynamic CSS Class & Icon Toggling

## Installation & Running Steps
1. Navigate to the project directory:
   ```bash
   cd Practical-5
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open your browser at `http://localhost:5173`.
